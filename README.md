## Tecnologías utilizadas

Para el desarrollo de este laboratorio se utilizaron diferentes herramientas que ayudaron en la creación, ejecución y almacenamiento de los ejercicios realizados con HTML5 y CSS3.

**Visual Studio Code:** se utilizó como editor de código para escribir y organizar los archivos HTML y CSS desarrollados durante el laboratorio.

**HTML5:** se utilizó para crear y estructurar el contenido de las páginas web, trabajando con elementos como tablas, enlaces, secciones, encabezados y otros elementos semánticos.

**CSS3:** se utilizó para modificar la presentación visual de las páginas web mediante estilos, clases, identificadores y diferentes tipos de selectores.

**Navegador Web:** se utilizó para visualizar y comprobar el funcionamiento de los archivos HTML y los estilos CSS aplicados.

**GitHub:** se utilizó como repositorio en línea para guardar y compartir los archivos correspondientes a los ejercicios realizados durante el laboratorio.

---

## Información Relevante sobre el Desarrollo del Laboratorio

Este laboratorio permitió poner en práctica conceptos fundamentales de HTML5 y CSS3. Los ejercicios se enfocaron en la creación y estructuración de tablas, el uso de etiquetas semánticas, hipervínculos, metadatos y la aplicación de estilos mediante diferentes selectores CSS.


Además, los ejercicios fueron ejecutados en el navegador para comprobar el funcionamiento del código y observar de forma práctica cómo HTML estructura el contenido y CSS controla su presentación visual.
